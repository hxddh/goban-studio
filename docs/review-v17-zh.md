# Goban Studio v17.0.0 发布后评估与 v18 规划（全面质变）

评估日期：2026-11-21 · 对象：`main` @ `22a9eff`（v17.0.0）· 依据：

- 中英文、浅色和深色下的逐屏走查，对局中的棋盘按 2 倍像素放大看；
- 棋盘代码（`theme.js`、`board-surface.js`、`board.js`）；
- 用真实渲染器做的两个棋盘配色原型（`docs/board-v18-options.png`）；
- 仓库所有者的反馈：“棋盘还是不优雅，颜色和视觉有些怪，棋盘要利于对弈”。

## 0. 结论

v15 到 v17 解决的是“有没有、对不对、稳不稳”：

- 功能：评价、复盘、课程、名局、布局库；
- 验证：KataGo 复核、打包自检；
- 稳定：PR 阶段打包、平台路径对照。

这些现在都在，而且被检查着。

**但用户坐下来下一盘棋时看到的东西，仍然不够好。** 棋盘颜色发灰、发粉，木纹像细竖线。深色模式下棋盘变成浑浊的橄榄棕，黑子沉进去。鼠标预览像一块污渍。这是产品的门面，也是使用时间最长的地方。

**v18 的“质变”不是加功能，而是让“下一盘棋”这件事从头到尾都精致、清楚。** 依次是：

1. 棋盘本身：材质、棋子、信号、深浅色；
2. 对局界面的手感；
3. 全应用视觉统一到同一套语言；
4. 让真实用户第一次打开就顺利：Windows 安装程序、首次启动。

不加新页面、新设置、新模式。凡是要动的，都是替换现有的东西，不在旁边再加一个。

## 1. 棋盘诊断（具体原因）

| # | 现象 | 原因（代码里） | 影响对弈 |
| --- | --- | --- | --- |
| G1 | 浅色棋盘发灰、发粉，像纸板 | 木色 `#E4CB9A` 饱和度低，偏米灰；暗角 7% | 白子和棋盘对比弱，白子不“亮” |
| G2 | 木纹像一根根细竖线 | 细纹透明度最高约 0.07，且与竖线网格平行 | 读盘时多出“假线”，视觉噪声 |
| G3 | 深色模式棋盘浑浊 | 木色压到 `#9E7E4E`，再叠 20% 暗角 | 黑子与棋盘对比不足，网格发糊，最影响对弈 |
| G4 | 鼠标预览像污渍 | 黑子预览以 38% 透明度画在木上，变成灰褐色 | 看不清下一手是什么颜色 |
| G5 | 白子下半部发灰 | 白子贴图的阴影偏重 | 白子像塑料球，不像蛤碁石 |
| G6 | 棋盘像塑料面板 | 边缘高光加投影，木框宽 | 观感廉价 |
| G7 | 坐标偏淡 | 文字透明度 0.6，字号小 | 读坐标吃力 |
| G8 | 深色模式手顺里的黑子是空心灰圈 | 列表的棋子图标在深色下没有处理 | 分不清黑白 |

原型对比（`docs/board-v18-options.png`，用真实渲染器、同一局面截图）：

- **方案 A·榧木**：木色 `#DFB66E`，细纹降到原来的四成，网格更实，暗角减弱。深色模式下棋盘仍是浅木色（`#C29858`），只把周围界面调暗：黑白子对比都清楚。
- **方案 B·淡榧**：`#E6C487`，比 A 更柔和一些。
- 两个方案都只改了颜色。G4（预览）、G5（白子）、G6（边框）要在 v18 里单独做。

**建议**：先由仓库所有者在 A、B 之间选一个，或指出方向，再实现。v15 时的“木纹再淡一点”导致了现在的偏灰，所以这一次先定稿，后动手。

## 2. v18 规划：对弈之美

### 2.1 棋盘重做（先定稿，再实现）

| # | 内容 | 衡量 |
| --- | --- | --- |
| B1 | **木色与木纹**：按选定方案；细纹不再与网格平行可见，只保留宽的色带；去掉塑料感的高光边，木框变窄 | 2 倍像素截图下看不到“细竖线”；白子与木色亮度差、黑子与木色亮度差都有下限（写成单元测试） |
| B2 | **深色模式**：棋盘保持浅木色，只降亮度约 10–15%；周围界面是暗的；去掉暗角 | 深色下黑子与棋盘的亮度差不低于浅色模式的 80% |
| B3 | **棋子**：<br>• 白子像蛤碁石：亮、微暖，阴影只在边缘；<br>• 黑子像那智黑石：哑光，左上一点柔光；<br>• 一个光源，阴影一致 | 9、13、19 路，非 Retina 和 Retina 下都干净 |
| B4 | **对弈信号**：<br>• 预览是干净的半透明同色棋子，没有褐色；<br>• 最后一手标记在黑白子上都清楚；<br>• 星位与线宽成比例；<br>• 坐标清晰（对比度 ≥ 4.5:1） | 每项有截图基线和对比度测试 |
| B5 | **高对比棋盘**（设置里已有）保留不动，作为无障碍选项 | — |

### 2.2 对局界面的手感

| # | 内容 | 衡量 |
| --- | --- | --- |
| P1 | 对局时棋盘尽量大，右侧面板更紧凑；对手和你的信息、轮到谁、提子数一眼可见 | 1280×800 下 19 路棋盘的每格不小于现在 |
| P2 | 深色模式的手顺图标、形势条、数子结果的颜色在新棋盘上重新调 | 深浅色各一组截图基线 |
| P3 | 落子、提子、终局数子的动效和声音再走一遍：短、轻、不打扰 | 由人试听试看（H1） |
| P4 | 对手思考时的提示更安静：不闪、不跳 | — |

### 2.3 全应用视觉统一

- 把棋盘的木色、墨色作为整个应用的主色调来源：强调色、图表、缩略图都取自同一套变量，不再各自定颜色。
- 深色模式整体再过一遍：现在界面是中性黑，棋盘是暖色，两者要协调。
- 衡量：今天、下棋、练习、棋谱、复盘、设置六个场景，浅色和深色各一组截图，由仓库所有者看过再定。

### 2.4 第一次打开就顺利

| # | 内容 | 说明 |
| --- | --- | --- |
| D1 | **Windows 安装程序**（MSI，用 CI 构建）：开始菜单、桌面图标、`.sgf` 关联、卸载 | 不需要证书也能做；签名以后再加 |
| D2 | 首次启动：从打开到第一盘棋落下第一子，不超过 3 步 | 界面检查里量步数 |
| D3 | macOS 公证、Windows 签名 | 需要仓库所有者的证书（O1、O2），工作流已就绪 |

### 2.5 质量门槛（为了不再“看着怪”）

- **棋盘的视觉测试**：每种配色都有亮度差和对比度的单元测试；截图基线覆盖 9、13、19 路，浅色、深色和高对比，以及悬停、最后一手、数子。
- **先看后合**：棋盘、深色模式、整体视觉这三项，合并前都先把截图给仓库所有者看。

### 2.6 不做

- 新功能、新页面、新设置项、新的棋盘样式选项（替换标准棋盘，不再加一个）。
- 换内置网络、段位题、繁体中文：各自单独决定。

## 3. 仍需要真人

- **真机**：在 Mac 和 Windows 上各点一次“设置 → 引擎 → 测速”，记下数字；看一眼深浅色切换时的标题栏。
- **棋手**：看一下 KataGo 不认同的几处课程（`docs/lesson-audit.md`）。
- **v18 期间**：棋盘方案的选择，以及每一步截图的确认。

## 4. 发布门槛（v18）

1. 棋盘方案由仓库所有者选定；实现后的截图（浅色、深色，9、13、19 路）由仓库所有者确认。
2. 棋盘的亮度差和对比度测试全部通过。
3. 三个平台的打包自检和发布演练通过。
4. Windows 安装程序在 CI 上安装、启动、卸载一遍通过。
